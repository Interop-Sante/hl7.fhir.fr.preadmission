# Implementation Guide : Préadmission Hospitalière
Ce guide décrit les échanges de données entre un logiciel de prise de rendez-vous, un portail en ligne pour le patient, et le logiciel administratif de l'hôpital.
Les ressources utilisées sont `DocumentReference`, `Coverage`, `Encounter`, `Appointment`, et `Consent`.
