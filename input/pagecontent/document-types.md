# Types de documents pour la préadmission

Ce Code System regroupe les différents types de documents pouvant être transmis dans le cadre d’une préadmission hospitalière.

**Canonical URL** : [`http://hl7.fr/fhir/fr/preadmission/CodeSystem/document-type-code-system`](http://hl7.fr/fhir/fr/preadmission/CodeSystem/document-type-code-system)  
**Statut** : `active`  
**Version** : `1.0.0`

## Liste des codes

| Code | Affichage | Définition |
|------|-----------|------------|
| `CNI` | Carte d’identité | Copie d'une carte nationale d'identité. |
| `CNI_RECTO` | Recto Carte d’identité | Image ou scan du recto de la carte d'identité. |
| `CNI_VERSO` | Verso Carte d’identité | Image ou scan du verso de la carte d'identité. |
| `ATTEST_VITALE` | Carte Vitale | Copie ou photo de la carte Vitale de l'assuré. |
| `PASSPORT` | Passeport | Copie du passeport. |
| `JUSTIFICATIF_ID` | Justificatif d'identité | Tout autre document officiel permettant de justifier son identité. |
| `MUTUELLE` | Carte mutuelle | Carte de mutuelle de santé. |
| `MUTUELLE_RECTO` | Recto Carte mutuelle | Recto de la carte de mutuelle. |
| `MUTUELLE_VERSO` | Verso Carte mutuelle | Verso de la carte de mutuelle. |
| `LIVRET` | Livret de famille | Livret de famille (pages concernées). |
| `JUSTIFICATIF_DOM` | Justificatif de domicile | Facture ou document prouvant le domicile. |
| `CARTE_SEJOUR` | Carte de séjour | Carte de séjour en cours de validité. |
| `ARRET_TRAVAIL` | Arrêt de travail | Document médical attestant d’un arrêt de travail. |
